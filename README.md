# ROBOCON2026 福州大学浮舟湿地战队沙排之王排球机器人上位机算法思路开源

## 前言
>本开源包含本次2026年第26届ROBOCON——沙排之王赛道的上位机算法代码以及开发思路分享。  
>
>需要说明的是，受项目开发周期所限，前后算法调试时间只有不到20天。期间从最初复杂的**识别-落点预测-规划**方案连续迭代了3版，最终改为**视觉伺服PID方案**。代码虽有基础调试验证，但因实际效果欠佳、与赛场工况不符，最终精简为仅保留自动辅助击打功能，上位机在比赛前被取消。
>  
> 本战队今后不再参加ROBOCON，故整理资料选择开源，纪念这份心血，也希望能为大家带来一些思路。
>  

## 仓库说明
分为两个大文件夹：
- `drop_point_prediction`为最初立项时设计好的架构并不断优化的方案，思路为识别定位-状态估计-轨迹预测-规划，唯一遗憾的是缺乏时间调试优化，属于是理论可行但极难实现的高门槛方案。
    
- `ibvs`为最后一星期内根据一篇 IEEE 论文思路修改出来的、基于 PID 控制的视觉伺服方案，门槛低，也是短期效果更好的方案，但缺陷也显而易见，不能根据球的具体飞行方向去预判。  
  
- 具体部署方法与原理、实现效果、项目架构、调试经历将在各自文件夹下详细说明。 
   
- 最后这两个方案都是未能成功实现稳定接球的，还请酌情考虑，理性参考。
