# ROBOCON2026 福州大学浮舟湿地战队沙排之王排球机器人上位机算法思路开源

## 前言
>本开源包含本次2026年第26届ROBOCON——沙排之王赛道的上位机算法代码以及开发思路分享。  
>
>值得说明的是，由于战队内管理与项目开发周期问题，前后算法调试时间只有不到20天，在短时间内被迫被要求从原先复杂的**识别-落点预测-规划**算法临时连续修改3版方案改为**视觉伺服pid方案**，其本身代码虽有基础调试验证，但都由于实际效果不尽人意，以及赛场实际工况无法上场，被一路阉割至只剩只有自动辅助击打功能，甚至是最后干脆取消上位机。不过最后实际赛场上也是能发现今年比赛上位机视觉算法并不是个很核心决定性的因素，除了东北大学以外几乎都是
>  
> 鉴于本战队今后不再参加ROBOCON以及种种原因，故整理资料选择开源，以纪念这最后可有可无的心血，为大家带来我的思路。
>  

## 仓库说明
分为两个大文件夹：
- `drop_point_prediction`为最初立项时设计好的架构并不断优化的方案，思路为识别定位-状态估计-轨迹预测-规划，唯一遗憾的是缺乏时间调试优化，属于是理论可行但极难实现的高门槛方案。
    
- `ibvs`为最后一星期内在管理层要求下紧急根据一篇ieee论文思路修改出来的，基于PID控制的视觉伺服方案，门槛低，也是短期效果更好的方案，但缺陷也显而易见，不能根据球的具体飞行方向去预判。  
  
- 具体部署方法与原理、实现效果、项目架构、调试经历将在各自文件夹下详细说明。 
   
- 最后这两个方案都是未能成功实现稳定接球的，还请酌情考虑，理性参考。
